# Simpsons Quotes

The Simpsons Quotes app is a React application that fetches and displays quotes from The Simpsons API. Users can search, like, and delete quotes with dynamic UI updates. React Hooks (useState, useEffect, useCallback) are employed to manage state and side effects efficiently.


## Tech Stack

React, Axios


## Features

- Search for characters
- Like quotes
- Delete quotes
